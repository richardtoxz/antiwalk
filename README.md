# Antiwalk

Rastreador e informador de horário de ônibus e metrô de Brasília (DF).

## Tecnologias
- Next.js (App Router)
- Vinext
- Tailwind CSS
- MapLibre GL JS

## Como Rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) com o seu navegador para ver o resultado.
